# Multi-Persona Synthesis Prompt

Given the extracted frameworks from `extract.md`, synthesise ONE answer in the following structure. Every section must be filled with specifics from the user's situation — no generic placeholders.

---

## Output Structure

### 1. Diagnosis
What problem is the user actually solving? (Not the surface question — the underlying constraint.)
1–2 sentences. Be direct.

---

### 2. Strategy
The routed operator logic applied to their context.

- Lead with the operator whose framework is most directly applicable
- Show how the second operator's framework extends or reinforces the first
- If they conflict, present both options with the decision criterion: "If [condition A], do [Operator 1's approach]. If [condition B], do [Operator 2's approach]."

Length: 150–300 words. Specific. No hedging.

---

### 3. Copy / Script / Asset
The tangible deliverable for this route:

| Route | Deliverable |
|-------|------------|
| `offer` | Grand Slam Offer card (stack + guarantee + price anchor + deadline) |
| `sales-script` | Opening + discovery loop + objection loop + close language |
| `funnel` | Funnel map with page-by-page notes + conversion benchmarks |
| `positioning` | Positioning one-pager (market definition + differentiator + exclusion + headline) |
| `content-engine` | 90-day engine overview + pillar content brief + hook stack (10 options) |
| `execution` | 30-day sprint plan + daily non-negotiables + forcing function |

This section is the work product. It must be usable immediately without further interpretation.

---

### 4. Psychology
The buying trigger, objection loop, or state shift being engineered.

Answer: What is happening in the buyer's or user's mind that makes this strategy work?
- Name the specific psychological mechanism (scarcity, certainty transfer, pattern interrupt, social proof cascade, etc.)
- Explain why the operator's framework triggers it
- Flag any psychological risk: what could backfire and how to prevent it

Length: 75–150 words.

---

### 5. Action
**Next 1 day**: The single action to take in the next 24 hours. Concrete. One sentence.

**Next 7 days**: 3–5 actions that build the foundation. Bullet list.

**Next 30 days**: The milestone that proves the strategy is working. One sentence.

**This week's forcing function**: The one commitment to make in the next 48 hours that makes inaction more expensive than action.

---

### Stack Used
`Stack used: [Operator A] + [Operator B]`

---

## Synthesis Rules

- Never give advice that is not traceable to a specific operator framework from the reference files
- If the user's question spans two routes, run both and merge at the Strategy step — do not produce two separate answers
- Prefer one sharp, confident recommendation over a hedged menu of options
- The Copy/Asset section must be immediately usable — if the user cannot act on it without further research, rewrite it
- Maximum 3 operators in any single answer — beyond that, the output becomes noise
