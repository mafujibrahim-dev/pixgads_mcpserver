# Route: execution — Robbins + Cardone Stack

**Trigger keywords**: burnout, follow-through, team performance, speed, discipline, not executing, stuck, procrastinating, scaling team, accountability, momentum, breaking bottlenecks

**References**: `references/robbins.md`, `references/cardone.md`

---

## Output: 30-Day Execution Sprint

When this route is active, diagnose the specific execution failure and build a 30-day sprint. Fill in the user's actual bottleneck — do not output generic productivity advice.

---

### 1. RPM Block — Result, Purpose, Massive Action (Robbins)

**R — The Result** (must be specific and time-bound):
> "By [date 30 days from now], I will have achieved [specific, measurable outcome]."

Not: "I want to grow my business."
Yes: "By June 7, I will have closed 5 new clients at $3,000 each = $15,000 in new revenue."

**P — The Purpose** (must create emotional urgency):
> "I must achieve this because [consequence of not achieving it] and [what it makes possible if achieved]."

If the user cannot answer the Purpose question with emotional conviction, the sprint will fail. Assign: "Write 3 reasons why this matters and read them aloud every morning."

**M — Massive Action Plan** (not a to-do list — a force-ranked plan):

| Priority | Action | Owner | Deadline | Non-negotiable? |
|----------|--------|-------|---------|----------------|
| 1 | [highest-leverage activity] | | | Yes |
| 2 | [second highest] | | | Yes |
| 3 | [third] | | | Yes |
| … | [supporting tasks] | | | No |

**Non-negotiables**: 2–3 actions per day that happen regardless of anything else. These are protected commitments, not aspirational tasks.

---

### 2. State / Story / Strategy Diagnosis (Robbins)

Most execution failures are misdiagnosed as strategy problems. Diagnose first:

| Layer | Question | If broken |
|-------|---------|----------|
| **State** | "Do I have the energy, certainty, and focus to execute?" | Fix physiology, priming, morning ritual first |
| **Story** | "Am I telling myself a story that limits my action?" | Identify the limiting belief, challenge it, replace it |
| **Strategy** | "Do I have the right plan, or am I executing the wrong thing?" | Only address this if State and Story are not the problem |

**Common limiting stories to surface**:
- "I'm not ready yet" (waiting for perfect conditions)
- "I don't deserve this level of success"
- "This isn't going to work for me"
- "I don't have enough [time/money/team]"

**Reframe protocol**: "Is this story 100% true? What would I do if it wasn't true?"

---

### 3. Cardone Daily Non-Negotiables

A high-performance day is built from non-negotiable actions that happen before any reactive work:

**Morning block (before email/messages)**:
- [ ] Priming ritual (Robbins — 10 min: gratitude, vision, physiology)
- [ ] Review the RPM result and purpose
- [ ] Identify today's three highest-leverage actions
- [ ] Begin the first action immediately

**Pipeline non-negotiables** (customise to role/business):
- [ ] [X] new outreaches made
- [ ] [X] follow-ups completed
- [ ] [X] proposals / offers sent
- [ ] Revenue-generating task done before administrative task

**Cardone rule**: "Do not go to work to work. Go to work to produce." Protect production time fiercely. Schedule reactive work (email, Slack, meetings) into fixed blocks; never let it consume the whole day.

---

### 4. One Forcing Function Per Week (Robbins)

A forcing function makes inaction more painful than action. Without one, execution is optional.

**Forcing function options**:
- Public commitment (announce the goal or deadline publicly)
- Financial stake (pay a deposit, hire someone, book the event)
- Social accountability (weekly check-in with a peer who will challenge you)
- Hard deadline with consequence (if X isn't done by Friday, Y happens)
- Pre-sold delivery (sell the thing before it's built — now you must deliver)

**Assignment**: Before the sprint begins, identify one forcing function for week 1 and install it within 48 hours.

---

### 5. Decision-Under-Pressure Protocol (Robbins + Cardone)

For the one critical call / decision that is the bottleneck:

**Step 1 — State reset** (Robbins):
Before the hard conversation, call, or decision:
- 3 deep breaths (physiological reset)
- Power posture for 2 minutes
- Recall a time you executed perfectly under pressure (anchor that state)

**Step 2 — The decision frame** (Cardone):
> "What is the cost of NOT making this decision today?"

If the cost of inaction is greater than the cost of a wrong decision, decide now and adjust. Perfect information is rarely available — and waiting is itself a decision.

**Step 3 — The 10X filter** (Cardone):
> "What would I do if I were 10× more confident than I am right now?"

Do that. Scale back only if there is a specific, logical reason to — not because of fear.

**Step 4 — Commit and execute** (Cardone):
Once the decision is made, do not revisit it unless new information arrives. Doubt after commitment kills momentum. Execute fully, then evaluate results.

### 30-Day Sprint Structure

| Week | Focus | Forcing Function | Daily Non-negotiable |
|------|-------|-----------------|---------------------|
| 1 | Install the system | [specific commitment] | [2–3 actions] |
| 2 | Build momentum | Mid-sprint check-in | [2–3 actions] |
| 3 | Accelerate | Raise the target by 10% | [2–3 actions] |
| 4 | Close and review | Public results report | [2–3 actions] |

**End-of-sprint review** (Robbins CANI loop):
1. What worked?
2. What didn't?
3. What will we do differently?
4. What is the next 30-day result?
