### 1. Hook → Story → Offer Page (Brunson)

**Hook** (headline + sub-headline on the entry page):
- Must create a pattern interrupt — stops the scroll or the skim
- Must speak the exact language the prospect uses internally
- Format: "[Curiosity gap or pain statement] — [promise of specific outcome]"
- Variants to test: problem-agitation, contrarian claim, "who else wants X", bold number

**Story** (body copy / VSL narrative):
- Origin story: how you found the solution (relatability before authority)
- The epiphany bridge: the moment everything changed
- Proof of the new opportunity: it works for you AND for others like them
- Future pace: what their life looks like after they implement

**Offer** (bottom of page / close of VSL):
- Do not reveal price until after the stack
- Stack deliverables with stated values before showing price
- Insert guarantee immediately before the CTA button
- CTA: one action, stated simply, repeated at top and bottom

### 2. Value Ladder Placement (Brunson)

Map the user's existing offers to the value ladder:

```
[High-ticket backend] → $[price] — [what it is]
[Core offer]         → $[price] — [what it is]
[Tripwire]           → $[price] — [what it is]

```

**Gap diagnosis**: Which rungs are missing? A missing tripwire means cold traffic has no low-risk entry point. A missing high-ticket backend means you are leaving most of the revenue on the table.

### 3. Lead Magnet → Tripwire → Core → Continuity (Hormozi)

**Lead magnet requirements** (Hormozi):
- Solves one specific, immediate problem
- Consumed in under 15 minutes (checklist, template, short video)
- Creates appetite for the core offer
- Must attract the right buyer — not everyone

**Tripwire** ($7–$97):
- Converts a subscriber into a buyer — breaks the psychological barrier
- Must over-deliver on value relative to price
- Should be a direct stepping stone toward the core offer's transformation

**Core offer** ($[price]):
- The main vehicle for the dream outcome
- Must include all Hormozi value equation elements
- Guarantee is mandatory here

**Continuity / profit maximiser**:
- Recurring: membership, coaching, software, community
- One-time upsell: done-for-you, advanced implementation, cohort

---

### 4. Offer Inserted at Highest-Intent Moment (Hormozi)

Highest-intent moments in a funnel — place the core offer at the first one that applies:

| Moment | Why Intent is High |
|--------|------------------|
| Thank-you page after lead magnet opt-in | They just raised their hand |
| Immediately after tripwire purchase | Momentum is highest right after a yes |
| End of webinar / VSL | Belief has been built over 30–60 mins |
| Application confirmation | They already invested time to apply |
| Post-delivery of quick win | They just experienced a result |

**Rule**: Do not bury the offer in a nurture sequence if a high-intent moment exists earlier.

---

### 5. Conversion Metric Targets Per Step

Set minimum viable benchmarks. If below these, fix that step before spending more traffic:

| Step | Benchmark |
|------|----------|
| Landing page opt-in (cold traffic) | ≥ 30% |
| Landing page opt-in (warm traffic) | ≥ 50% |
| Tripwire conversion (from opt-in) | ≥ 1–3% |
| Core offer conversion (warm/retargeted) | ≥ 1–5% |
| Webinar show rate | ≥ 25–40% |
| Webinar close rate | ≥ 5–15% |
| Upsell take rate | ≥ 20–35% |

**Diagnosis priority**: Fix from the bottom of the funnel up. A broken close is more expensive to ignore than a leaky opt-in.

---

### Funnel Architecture Templates

**Simple lead gen funnel**:
`Ad / SEO → Squeeze page → Thank-you (tripwire offer) → Email sequence → Core offer`

**Webinar funnel**:
`Ad → Registration page → Indoctrination sequence → Live/auto webinar → Replay + close sequence`

**Application / high-ticket funnel**:
`Content → VSL page → Application → Confirmation → Strategy call → Close`

**Product launch funnel**:
`Pre-launch content (3 videos) → Cart open email → Sales page → Cart close (deadline) → Downsell`
